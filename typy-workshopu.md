# Typy workshopu a jejich struktury

Klientský workshop má typicky jednu z těchto metodik. Každá určuje, jaké sekce má zápis mít.

## 1. Strategický workshop (byznys model + Future scenarios + AARRR + cíl)

Typický **úvodní workshop** projektu (web redesign, strategie). Cílem je **shoda na cílech projektu**, byznys kontextu a metrikách.

Sekce zápisu:

1. **Kontext a cíl workshopu** — anotace, účastníci s rolemi
2. **Byznys model klienta** — jak vzniká hodnota (příjmové linky, marže, distribuční kanály)
3. **Future / Anti-future scénáře** — ideální vs. noční můra po dokončení projektu (= identifikace rizik)
4. **AARRR funnel** — cíle projektu po fázích (Akvizice → Aktivace → Příjmy → Retence → Doporučení)
5. **Hlavní cíl projektu + metriky** — vybráno hlasováním
6. **Klíčová strategická zjištění** — implikace pro další fáze
7. **Hypotézy a otevřené otázky**

## 2. Value Proposition Canvas (VPC) + Customer Journey

Workshop zaměřený na **zákazníky** — kdo jsou, co potřebují, jak se rozhodují, v čem je klient unikátní.

Sekce zápisu:

1. **Potřeby zákazníků** — jobs / pains v kontextu klienta
2. **Řešení klienta** (produkty + služby)
3. **Alternativy a konkurence** — co dělá zákazník, když klient neexistuje
4. **Klíčové unikátní vlastnosti (USP)** — co má jen klient, nebo je těžké zkopírovat
5. **Hodnota pro zákazníka** — co ze USP zákazník reálně čerpá
6. **Zákaznické segmenty** — primární dělení + subkategorie
7. **Detail per segment** (pokud byly breakout místnosti):
   - Subsegmenty
   - Hlavní potřeby (Needs)
   - Motivace / Gains
   - Obavy / Pains
   - Customer journey mapa
   - Implikace pro web
8. **Důvěryhodnost** — co u klienta podporuje důvěru
9. **Konkrétní příběhy a use cases** — pro skici a copy
10. **Slovník klienta**
11. **Hypotézy a otevřené otázky**

## 3. Sense-making workshop

Workshop **po výzkumu** — společná interpretace dat z rozhovorů a analytiky. Cílem je posun z dat na insighty a strategická rozhodnutí.

Sekce zápisu:

1. **Vstupy (data)** — co se prezentovalo (rozhovory × N, analytika, klíčová slova)
2. **Klíčové insighty** — co data ukazují (4–8 hlavních zjištění)
3. **Segmentace zákazníků** — finalizace segmentů na základě výzkumu
4. **Persony / JTBD** (pokud z workshopu vznikly)
5. **Opportunity areas** — kde je prostor zlepšit / strategicky zaměřit
6. **Strategický rámec pro IA** — co z toho plyne pro architekturu webu
7. **Otevřené otázky** — co potřebujeme dořešit ve strategii nebo prototypu

## 4. Customer Journey Mapping (samostatný)

Workshop zaměřený na **mapování zkušenosti zákazníka** napříč touchpointy.

Sekce zápisu:

1. **Persona / segment**, pro kterou se mapuje
2. **Fáze cesty** (pre-awareness → awareness → consideration → decision → onboarding → use → retention → referral)
3. **V každé fázi:** akce zákazníka, touchpointy, myšlenky, emoce, friction points
4. **Moments of truth** — kritické momenty, které rozhodují o úspěchu
5. **Příležitosti pro zlepšení** — kde web / služba / komunikace může pomoci
6. **Implikace pro projekt**

## 5. Workshop revize skic / prototypu

Workshop, kde se prezentují **návrhy** (wireframy, prototyp) a klient dává **zpětnou vazbu**.

Sekce zápisu:

1. **Co se prezentovalo** — verze prototypu, klíčové novinky
2. **Zpětná vazba per obrazovka / sekce** — co se líbilo, co je třeba změnit
3. **Sporné body** — kde tým HoŘ a klient nemají shodu
4. **Akční seznam pro další iteraci** — co změnit, co nechat
5. **Otevřené otázky pro klienta** — rozhodnutí, která musí udělat klient

> Pro tento typ workshopu možná dává větší smysl použít samostatný postup na zpracování zpětné vazby z review.

## 6. Lean Canvas / Business Model Canvas

Méně častý v HoŘ workflow, ale občas se vyskytne. Sekce zápisu kopírují strukturu canvasu:

1. Customer Segments
2. Problem
3. Unique Value Proposition
4. Solution
5. Channels
6. Revenue Streams
7. Cost Structure
8. Key Metrics
9. Unfair Advantage

Plus klasické sekce: slovník, hypotézy, otevřené otázky.

## Když workshop nezapadá do žádné šablony

Postav strukturu **podle obsahu workshopu**, ale drž obecnou kostru:

```
Frontmatter
TL;DR
Kontext a cíl workshopu
{Tematické sekce podle průběhu workshopu}
Slovník klienta
Konkrétní příběhy a use cases (pokud byly)
Hypotézy k ověření
Otevřené strategické otázky
Atmosféra a meta-pozorování (volitelné)
```

## Hybrid workshopy

Reálné workshopy bývají **hybridní** — typicky strategický + AARRR, nebo VPC + Journey, nebo sense-making + persony. **Neboj se kombinovat sekce z více šablon.** Důležité je, aby zápis logicky pokryl, co se na workshopu odehrálo.
